[@angelblanco/eslint-config 3.0](https://github.com/angelblanco/eslint-config) is available on npm. You can now lint your [Tailwind CSS](https://tailwindcss.com/) classes.

When I started this blog in 2025, there was no ESLint plugin for Tailwind CSS v4 yet. This week I'm updating my open source repositories, and [eslint-plugin-tailwindcss](https://github.com/francoismassart/eslint-plugin-tailwindcss) is finally ready.

It's impressive how much the stack you use can change in a year, but I'll write about that in upcoming posts.

## Tailwind CSS

Install the plugin:

```bash
pnpm add -D eslint-plugin-tailwindcss
```

Then enable the `tailwind` option and point it to your CSS entry file:

```js [eslint.config.js]
import eslintConfig from '@angelblanco/eslint-config';

export default eslintConfig(defaultOptions => ({
  ...defaultOptions,
  tailwind: {
    cssConfigPath: 'app/assets/css/main.css',
  },
}));
```

It's disabled by default. If your CSS lives at `src/style.css`, `tailwind: true` is enough.

## Latest versions

3.0 also updates to [@antfu/eslint-config](https://github.com/antfu/eslint-config) v10 and ESLint 10. Expect `eslint --fix` to reformat some multi-line arrays, objects and ternaries the first time you run it.
