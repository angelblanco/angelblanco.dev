[@angelblanco/eslint-config 3.0](https://github.com/angelblanco/eslint-config) ya está disponible en npm. Ahora puedes pasar el linter por tus clases de [Tailwind CSS](https://tailwindcss.com/).

Cuando empecé este blog y [creé mi propia configuración de ESLint](/es/blog/create-your-eslint-config/) en 2025, todavía no había un plugin de [ESLint](https://eslint.org/) para Tailwind CSS v4. En noviembre de 2026 estoy actualizando mis repositorios open source, y [eslint-plugin-tailwindcss](https://github.com/francoismassart/eslint-plugin-tailwindcss) por fin está listo.

Es impresionante cuánto puede cambiar en un año el stack que usas, pero de eso escribiré en próximos artículos.

## Activa el lint de Tailwind CSS

Instala el plugin (necesita Tailwind CSS v4):

```bash
pnpm add -D eslint-plugin-tailwindcss
```

Después activa la opción `tailwind` e indícale tu fichero CSS de entrada:

```js [eslint.config.js]
import eslintConfig from '@angelblanco/eslint-config';

export default eslintConfig(defaultOptions => ({
  ...defaultOptions,
  tailwind: {
    cssConfigPath: 'app/assets/css/main.css',
  },
}));
```

Viene desactivado por defecto. Si tu CSS está en `src/style.css`, basta con `tailwind: true`. El resto de [ajustes del plugin](https://github.com/francoismassart/eslint-plugin-tailwindcss#settings) van en el mismo objeto.

## Actualiza a @antfu/eslint-config v10 y ESLint 10

La 3.0 también actualiza a [@antfu/eslint-config](https://github.com/antfu/eslint-config) v10 y ESLint 10. Instala la última versión de ambos paquetes:

```bash
pnpm add -D eslint@latest @angelblanco/eslint-config@latest
```

La primera vez que ejecutes `eslint --fix` verás que reformatea algunos arrays, objetos y ternarios multilínea.
